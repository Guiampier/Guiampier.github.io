¿Cómo usar este generador?

Pegar Código Existente

Pega cualquier código con formato &#RRGGBB&X en el área de texto y haz clic en "Generar Código RGB" para ver el resultado.

Aplicar Estilos

Usa los botones de formato para aplicar negrita, cursiva, subrayado o tachado a tu texto.

Copiar y Usar

Copia el código generado y úsalo en plugins como Essentials, LuckPerms, o en comandos de Minecraft.

Formatos Soportados

Este generador funciona con códigos de color hexadecimales en formato &#RRGGBB y códigos de formato de Minecraft.

Códigos de Formato de Minecraft

&l - Texto en Negrita
&o - Texto en Cursiva
&n - Texto Subrayado
&m - Texto Tachado
&r - Reiniciar Formato
